# OBBO — موقع الإطلاق obbo.ly

صفحة هبوط ثابتة (HTML + CSS + JS) للنشر على GitHub Pages بالدومين `obbo.ly`.

## الملفات

- `index.html` — الصفحة كاملة
- `assets/` — الشعار + 5 صور (الشاحنة الرئيسية + 4 صور كاروسيل)
- `CNAME` — فيه `obbo.ly` (يخبر GitHub Pages بالدومين المخصص)

## تغيير نسبة الإنجاز

في أعلى `<script>` في `index.html`:

```js
const PROGRESS = 7; // ← غيّر هذا الرقم فقط (من 0 إلى 100)
```

## موعد الإطلاق

العد التنازلي ينتهي `1 يناير 2027 — 7:00 صباحاً بتوقيت ليبيا`
(`2027-01-01T07:00:00+02:00` في الكود).

## النشر على GitHub Pages

1. أنشئ مستودعاً عاماً جديداً باسم `obbo.ly` في منظمة `artiatechstudio`
   (مستودع عام — GitHub Pages لا يعمل من مستودع خاص في الخطة المجانية).
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع (الفرع `main`).
3. في المستودع: Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
4. بعد انتشار DNS فعّل Enforce HTTPS في نفس صفحة Pages.
